
# qa_guru_selenium_lesson_1

Учебный проект по автоматизации тестирования на Python и Selenium в рамках курса QA.GURU.

## Цель проекта

Изучение основ автоматизации UI-тестирования.

## Что изучается

- Python
- Selenium WebDriver
- Написание автотестов
- Работа с Git и GitHub
- Запуск и отладка тестов

## Структура проекта

В репозитории находятся учебные задания и примеры автотестов, выполненные в ходе первого урока.
